# Журнал замечаний пользователя и непрерывного обучения (`docs/user_remarks.md`)

Этот файл содержит замечания пользователя, оперативную обратную связь, предпочтения и извлеченные уроки, находящиеся в процессе проработки или внедрения.

> [!IMPORTANT]
> **Обязательное правило для агента**:
> 1. В начале КАЖДОГО нового диалога/хода агент ОБЯЗАН прочитать этот файл для загрузки актуальных замечаний и предпочтений пользователя.
> 2. При появлении новой критики, замечаний к архитектуре, коду или стилю работы агент ОБЯЗАН немедленно зафиксировать их в этом журнале.
> 3. После того как замечание полностью учтено и перенесено в постоянные канонические инструкции (`AGENTS.md`, `SKILL.md`, `references/`, `docs/<framework>-rules.md`), оно удаляется из этого журнала, чтобы не дублировать правила и не перегружать контекст.
